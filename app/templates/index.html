System Architecture & Integration Details

1. Containerization (Docker)

Python 3.11-slim optimized multi-stage build running Gunicorn/Flask WSGI server. Completely stateless application layer.

2. Redis In-Memory State

Acts as the centralized shared state across all replicas. Atomic INCR visitor_count prevents race conditions under high concurrency.

3. Kubernetes Orchestration

Multi-replica Deployment with ClusterIP & NodePort services. Automatic self-healing reconciles pods upon crash or termination.

4. Horizontal Pod Autoscaler (HPA)

Monitors CPU utilization via Metrics Server. Dynamically scales Flask pods from 2 to 6 replicas when load exceeds 50% CPU.
